# 忆境（Mnemo）UI 与交互设计

一个把《记忆法全景手册》落成"每天真的练一次"的原生 iOS App（SwiftUI，iOS 18+）。

## 一、设计原则（来自手册本身）

1. **先诊断，再选法** —— 方法库内置症状诊断，不给用户 40 个方法让他自己挑。
2. **四步闭环：输入 → 编码 → 提取 → 应用** —— 每个关卡都是"看完立刻回忆"，没有纯阅读模式。
3. **间隔重复是留存引擎**（产品方案原话）—— 所有训练结果自动生成复习卡，SM-2 排期，到期才出现。
4. **记忆精度分级** —— Lv.1 再认 → Lv.5 自动化，作为用户成长主轴。

## 二、信息架构（4 Tab）

```
今日 Today          训练 Drill           方法 Library         我的 Profile
├ 今日目标环(3关)    ├ 词表闪记(联想)      ├ 搜索 + 7类筛选      ├ 精度阶梯 Lv1–5
├ 复习队列(到期卡)   ├ 数字桩(组块)        ├ 选法诊断(10症状)    ├ 数据 2×2
├ 30天计划·第N天    ├ 记忆宫殿(定位)      ├ 40法列表→详情       ├ 30天计划进度
├ 今天学一法        └ 方法练习(→方法库)   └ 详情内生成复习卡    ├ 徽章 6 枚
└ 快速开始                                                 └ 数据重置
```

## 三、视觉语言

- **深夜书房 + 记忆宫殿暖光**：深色底 `#0A0B10`，左上琥珀光晕 + 右下青色微光，卡片为 5% 白玻璃 + 1px 描边（22px 圆角）。
- **七类一色**：编码基础=琥珀、空间=青、序列=紫、语言=粉、结构=蓝、深度=绿、复习=橙。颜色只用于分类标识与强调，不做大面积填充。
- **数字用 rounded 等宽**（正确率、天数、位数），中文标题重字重 + 大字号对比（30pt 标题 / 12.5pt 辅助）。
- 每次状态变化配触感反馈：选择用 selection、过关用 success、漏词用 medium/heavy impact。

## 四、核心交互

### 1. 词表闪记（闯关式状态机）
`准备(选5/10/15词) → 3-2-1倒数(大数字+触感) → 逐词展示(1.4–1.9s/词，可点屏推进/提前回忆) → 回忆输入(顿号分隔，模糊匹配：允许"一只灯塔") → 判分(逐词✓/✗+漏词标记) → 结果(得分环+反馈文案) → 存入复习队列`
- 展示页顶部有逐词进度条，节奏可中断（"提前开始回忆"）。
- 结果文案按得分分四档，引导下一步（换长词表 / 编夸张故事 / 先用5词建立信心）。

### 2. 数字桩
`选位数(10/14/20) → 数字按 3-2-3-2 组块显示(限时倒计时条) → 遮住 → 数字键盘输入 → 逐位对照网格(上行原数/下行所写) → 结果`
组块节奏来自手册：3-4 位一组、形象化（12→婴儿）。

### 3. 记忆宫殿（四阶段，最完整的一条交互线）
`选路线(我的家10/上班路8/教室6) → 熟悉路线(逐点高亮+圆点进度) → 放置(一位置一词，强调"发生动作") → 按序回忆(逐点输入，可"想不起来") → 结果(位置×词对照表) → 存卡`
- 内置路线是"锚点"，产品后续可让用户自定义路线。

### 4. 复习队列（SM-2）
- 卡片 3D 翻面；正面标卡种(词表/数字/宫殿/方法)与到期阶段，背面为答案。
- 四档评价 `忘了(20分钟) / 吃力(1天) / 记得(3天) / 秒答(更久)`，ease/interval 按 SM-2 更新；未掌握卡 20 分钟后回队。
- 空队列与完成态都有明确收尾（"下一批按记忆强度自动排期"）。

### 5. 方法详情
单屏纵向流：定义 → 儿童版一句话（引用卡）→ 原理 → 步骤（竖向时间线）→ 最适合/不适合双栏 → 案例 → 举一反三三阶 → 常见错误 → 组合建议 → 儿童版案例。
底部吸底操作：`标记已学` + `生成方法复习卡`（10 分钟后到期，把"看过"变成"要复习"）。

### 6. 今日页
- 目标环 0/3，完成后文案切换为"今日已完成"。
- 复习队列卡片即时反映到期数，一键进入复习。
- 30 天计划卡片：显示第 N 天主题+任务，可"标记完成"，完成后自动推进到下一天。
- "今天学一法"取第一个未学方法。

## 五、数据与持久化

- 全部状态（复习卡、错题本、每日统计、最佳成绩、连续天数、已学方法、计划进度）以 Codable JSON 存 `Documents/mnemo_state.json`，后台写盘，旧版本存档自动兼容。
- 无账号、无网络、无隐私采集（与产品方案的数据最小化原则一致）。

## 六、v2：多模式练习 · 错题强化 · 日历 · 艾宾浩斯

### 1. 每法三阶 × 五题型（由简到难）

| 阶段 | 定位 | 题型 |
| --- | --- | --- |
| L1 初阶 · 认得它 | 再认 | 概念配对（定义↔方法）、步骤定位（第 k 步是什么） |
| L2 中阶 · 分得清 | 辨析 | 材料适配（什么适合/不适合）、流程排除（哪步不属于该方法）、步骤定位 |
| L3 高阶 · 用得上 | 迁移 | 应用编码：给真实材料现场编码并默写，自评过关/卡住 |

- 题目全部由 methods.json 的结构化字段自动生成，干扰项取自同库其他方法，40 法 × 3 阶即 120 组关卡，无需人工出题。
- 入口：方法详情页「开始练习」→ 选阶（带"建议"标记）→ 答题引擎 `QuizRunnerView`。
- 每阶记录最好成绩；连续两阶高分自动建议升阶，错题多则建议回炉 L1。

### 2. 错题本与强化训练

- 练习中答错的选择/应用题自动入错题本：存原题、选项、你的答案、正确答案、解析、错误次数。
- 强化模式：按错误次数排序抽 10 题重做，答对两次才出库；答错次数 +1、重置进度。
- 支持按方法筛选、单题移除、清空错题本；错题同时会以低质量复习卡进入 SM-2 队列（20 分钟后到期）。
- 入口：首页错题卡（有错题时出现）、训练场卡片、我的页。

### 3. 学习日历

- 月历视图：每天按训练次数着色（圆点浓度 = 强度），可翻月，今天高亮、选中描边。
- 点击某天 → 当日明细（次数、正确率、每条记录的类型与得分）。
- 首页/我的页有「最近 7 天」条带，点击直达完整日历。

### 4. 艾宾浩斯遗忘曲线（复习科学）

- **曲线图**（Swift Charts）：虚线"不复习" R=e^(-t/S) 一天只剩三成；实线"按阶梯复习"每次复习后稳定性翻倍，30 天后仍保持八成以上。
- **复习阶梯**：5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天，共 9 个节点。
- **保持率估算**：每张卡 R = e^(-t/S)，S 由 SM-2 间隔推得；复习卡背面显示"当前保持率"，曲线页汇总平均保持率。
- **到期分布**：今天 / 明天 / 3 天内 / 本周 / 以后五档柱状分布，指导"先清今天到期的"。

## 七、启动参数（调试/演示）

`-tab today|drill|library|profile`、`-screen flash|number|palace|wrong|curve|calendar|review`、`-method <id>`、`-practice`（直达该法练习）、`-autostart`（跳过选阶直接答题）、`-seedDemo`（注入 9 天演示数据，仅首次）
