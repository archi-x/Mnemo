# 忆境（Mnemo）UI 与交互设计

一个把《记忆法全景手册》落成"每天真的练一次"的原生 iOS App（SwiftUI，iOS 18+）。

## 一、设计原则（来自手册本身）

1. **先诊断，再选法** —— 方法库内置症状诊断，不给用户 40 个方法让他自己挑。
2. **四步闭环：输入 → 编码 → 提取 → 应用** —— 每个关卡都是"看完立刻回忆"，没有纯阅读模式。
3. **间隔重复是留存引擎**（产品方案原话）—— 所有训练结果自动生成复习卡，SM-2 排期，到期才出现。
4. **记忆精度分级** —— Lv.1 再认 → Lv.5 自动化，作为用户成长主轴。

## 二、信息架构（4 Tab）

```
今日 Today          训练 Drill           方法 Library         我的 Profile
├ 今日目标环(3关)    ├ 词表闪记(联想)      ├ 搜索 + 7类筛选      ├ 精度阶梯 Lv1–5
├ 复习队列(到期卡)   ├ 数字桩(组块)        ├ 选法诊断(10症状)    ├ 数据 2×2
├ 30天计划·第N天    ├ 记忆宫殿(定位)      ├ 40法列表→详情       ├ 30天计划进度
├ 今天学一法        └ 方法练习(→方法库)   └ 详情内生成复习卡    ├ 徽章 6 枚
└ 快速开始                                                 └ 数据重置
```

## 三、视觉语言

- **两套配色，随时切换**：深夜（默认）与白天，第三项"跟随系统"。
  - 深夜：深色底 `#0A0B10`，左上琥珀光晕 + 右下青色微光，卡片为 5.5% 白玻璃 + 1px 描边（22px 圆角）。
  - 白天：纸感米白底 `#F4F1EA`，顶部暖光，卡片为 86% 白 + 8% 黑描边 + 3px 纸影，强调色压深到 `#B26A10` 以保证白字对比度。
- **实现方式**：所有颜色令牌都是 `UIColor { trait in … }` 的动态色，主题 = 窗口的 `colorScheme`。切换只调一个 `preferredColorScheme`，整屏即时换肤，不重建视图、不丢滚动位置、不需要重启。写死的 `Color.white.opacity(x)` 一律换成 `Theme.veil(x)`（深色=白叠层，浅色=黑叠层），强调色上的文字用 `Theme.onAccent`（深色黑、浅色白）。
- **七类一色**：编码基础=琥珀、空间=青、序列=紫、语言=粉、结构=蓝、深度=绿、复习=橙。浅色下同一套相位的深色版本，保证在白底上仍是文字级对比。颜色只用于分类标识与强调，不做大面积填充。
- **数字用 rounded 等宽**（正确率、天数、位数），中文标题重字重 + 大字号对比（30pt 标题 / 12.5pt 辅助）。
- 每次状态变化配触感反馈：选择用 selection、过关用 success、漏词用 medium/heavy impact。
- 切换入口在「我的 → 外观」，三张迷你界面缩略图直接预览，选中项琥珀描边 + 标签变色。

## 四、核心交互

### 0. 登录 / 本机档案

没有账号体系，登录在这里是"建立本机身份"：

`品牌头(同心圆环 + 忆字) → 昵称 → 4 个符号头像(脑/书/星/月) → 进入忆境 / 先用访客身份逛逛`

- 档案只写本机：昵称、头像、加入时间，加上 SHA-256 后的 4 位进入密码，全部落在 `mnemo_state.json`，不上传、不注册。
- 按钮不做禁用态：昵称留空直接按默认名"练习者"进入，避免一进来就卡在灰按钮上。
- 底部三连（40 个记忆法 / 间隔重复 / 四段闯关）既是卖点，也把长屏留白撑住。
- **设了密码之后**再启动就是解锁页：品牌头缩小 → 头像 + 昵称 + `Lv.N · 称号 · XP` → 4 点进度 → 自绘数字键盘（不受输入法影响）。第 4 位自动校验，错了抖动 + 失败触感 + "密码不对，再试一次"，对了直接进主界面。
- 密码在「我的 → 进入密码」里设置（连输两次确认）、手动锁定、切换身份；忘记密码只能清空本机档案（文案已明说）。
- 首页问候带上昵称（"夜深了，林小满"），登录不是一次性仪式。

### 1. 词表闪记（闯关式状态机）
`准备(选5/10/15词) → 3-2-1倒数(大数字+触感) → 逐词展示(1.4–1.9s/词 + 单词速条，可点屏推进/提前回忆) → 回忆输入(顿号分隔，模糊匹配：允许"一只灯塔") → 判分(逐词✓/✗+漏词标记) → 结果(得分环+用时+反馈文案) → 存入复习队列`
- 展示页顶部有逐词进度条，节奏可中断（"提前开始回忆"）。
- **回忆限时随词数伸缩**：`4 秒/词 + 8 秒缓冲`（5词28s / 10词48s / 15词68s）。进度条随剩余时间收缩，<34% 转黄、≤10 秒转红并触发一次触感提醒，归零自动交卷并标记"时间到"。
- 结果文案按得分分四档，引导下一步（换长词表 / 编夸张故事 / 先用5词建立信心）；超时另有独立说明。

### 2. 数字桩
`选位数(10/14/20) → 数字按 3-2-3-2 组块显示(限时倒计时条) → 遮住 → 数字键盘输入 → 逐位对照网格(上行原数/下行所写) → 结果`
组块节奏来自手册：3-4 位一组、形象化（12→婴儿）。

### 3. 记忆宫殿（四阶段，最完整的一条交互线）
`选路线(我的家10/上班路8/教室6) → 熟悉路线(逐点高亮+圆点进度) → 放置(一位置一词，强调"发生动作") → 按序回忆(逐点输入，可"想不起来") → 结果(位置×词对照表) → 存卡`
- 内置路线是"锚点"，产品后续可让用户自定义路线。

### 4. 复习队列（SM-2）
- 卡片 3D 翻面；正面标卡种(词表/数字/宫殿/方法)与到期阶段，背面为答案。
- 四档评价 `忘了(20分钟) / 吃力(1天) / 记得(3天) / 秒答(更久)`，ease/interval 按 SM-2 更新；未掌握卡 20 分钟后回队。
- 空队列与完成态都有明确收尾（"下一批按记忆强度自动排期"）。

### 5. 方法详情
单屏纵向流：定义 → 儿童版一句话（引用卡）→ 原理 → 步骤（竖向时间线）→ 最适合/不适合双栏 → 案例 → 举一反三三阶 → 常见错误 → 组合建议 → 儿童版案例。
底部吸底操作：`标记已学` + `生成方法复习卡`（10 分钟后到期，把"看过"变成"要复习"）。

### 6. 今日页
- 目标环 0/3，完成后文案切换为"今日已完成"。
- 复习队列卡片即时反映到期数，一键进入复习。
- 30 天计划卡片：显示第 N 天主题+任务，可"标记完成"，完成后自动推进到下一天。
- "今天学一法"取第一个未学方法。

## 五、数据与持久化

- 全部状态（复习卡、错题本、每日统计、最佳成绩、连续天数、已学方法、计划进度、本机档案）以 Codable JSON 存 `Documents/mnemo_state.json`，旧版本存档自动兼容（缺字段补空值）。
- 写盘走一条**串行队列**：先写的快照一定先落盘。早先用"取消上一个 Task 再起新的"的写法，会让先发起的空快照后落盘、覆盖掉刚种进去的数据，串行队列把这个竞态彻底消除。
- 无账号、无网络、无隐私采集（与产品方案的数据最小化原则一致）。

## 六、v2：多模式练习 · 错题强化 · 日历 · 艾宾浩斯

### 1. 每法三阶 × 五题型（由简到难）

| 阶段 | 定位 | 题型 |
| --- | --- | --- |
| L1 初阶 · 认得它 | 再认 | 概念配对（定义↔方法）、步骤定位（第 k 步是什么） |
| L2 中阶 · 分得清 | 辨析 | 材料适配（什么适合/不适合）、流程排除（哪步不属于该方法）、步骤定位 |
| L3 高阶 · 用得上 | 迁移 | 应用编码：给真实材料现场编码并默写，自评过关/卡住 |

- 题目全部由 methods.json 的结构化字段自动生成，干扰项取自同库其他方法，40 法 × 3 阶即 120 组关卡，无需人工出题。
- 入口：方法详情页「开始练习」→ 选阶（带"建议"标记）→ 答题引擎 `QuizRunnerView`。
- 每阶记录最好成绩；连续两阶高分自动建议升阶，错题多则建议回炉 L1。

### 2. 错题本与强化训练

- 练习中答错的选择/应用题自动入错题本：存原题、选项、你的答案、正确答案、解析、错误次数。
- 强化模式：按错误次数排序抽 10 题重做，答对两次才出库；答错次数 +1、重置进度。
- 支持按方法筛选、单题移除、清空错题本；错题同时会以低质量复习卡进入 SM-2 队列（20 分钟后到期）。
- 入口：首页错题卡（有错题时出现）、训练场卡片、我的页。

### 3. 学习日历

- 月历视图：每天按训练次数着色（圆点浓度 = 强度），可翻月，今天高亮、选中描边。
- 点击某天 → 当日明细（次数、正确率、每条记录的类型与得分）。
- 首页/我的页有「最近 7 天」条带，点击直达完整日历。

### 4. 艾宾浩斯遗忘曲线（复习科学）

- **曲线图**（Swift Charts）：虚线"不复习" R=e^(-t/S) 一天只剩三成；实线"按阶梯复习"每次复习后稳定性翻倍，30 天后仍保持八成以上。
- **复习阶梯**：5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天，共 9 个节点。
- **保持率估算**：每张卡 R = e^(-t/S)，S 由 SM-2 间隔推得；复习卡背面显示"当前保持率"，曲线页汇总平均保持率。
- **到期分布**：今天 / 明天 / 3 天内 / 本周 / 以后五档柱状分布，指导"先清今天到期的"。

## 八、v3：等级 · 题型扩展 · 推荐引擎 · 游戏化 · 目标 · 报告 · 排名

### 1. 学员等级（XP 体系）

- 经验来源：答对 2 XP/题、整组完成 +6、正确率 ≥ 90% 再 +6、复习评分 1–4 XP。
- 等级公式：每级需求 80×n 递增累计；Lv.1–10 对应「记性新手 → 自动化大师」十个称号。
- 跨级触发全屏升级动画（RootView 层的 LevelUpToast），并即时调整推荐题型。

### 2. 九种题型（v2 五种 + v3 四种）

| 题型 | 阶 | 说明 |
| --- | --- | --- |
| 概念配对 | L1 | 定义与方法的对应 |
| 方法归类 | L1 | 七大类归属 |
| 步骤定位 | L1/L2 | 第 k 步做什么 |
| 原理溯源 | L2 | 为什么有效（干扰项为其他方法原理） |
| 材料适配 | L2 | 什么材料适合/不适合 |
| 流程排除 | L2/L3 | 哪步不属于该方法 |
| 步骤衔接 | L2 | 做完某步的下一步 |
| 案例归属 | L3 | 给案例判断用了哪种方法 |
| 应用编码 | L3 | 真材料编码 + 自评默写 |

- 题目全部由出题引擎从 40 法知识库生成，无需人工录题。
- `buildAdaptiveExercises(learnerLevel:)` 按学员等级挑题型：低等级认概念，高等级上案例辨析与编码。

### 3. 智能推荐引擎

优先级从高到低：错题强化（反复错加权）→ 到期复习 ≥ 3 张 → 薄弱方法（方法维度正确率 < 75%）→ 差一星收满 → 开新法 → 升级挑战（距下一级 ≤ 60 XP）。首页展示 Top 3，每条带理由，点击直达对应页面。

### 4. 游戏化闯关

- 按学龄段拆成四套玩法（详见第九节），共 45 关 × 三档难度。
- 解锁规则：段内按序，前一关拿到 1 星解锁下一关；「继续」按钮直达下一个未通关档位。
- 星图顶部显示本段星数/全段星数、等级与 XP；我的页徽章「摘星十枚」「进阶三级」。

### 5. 目标计划

- 六类目标：每日训练、每周训练、连续打卡、收集星星、正确率、掌握方法；每类三档预设，可增删（同类去重）。
- 进度实时由统计数据推导，不需要手动打卡；达成后显示「保持住」。
- 首次启动自动给三个默认目标（每日 3 关 / 每周 15 关 / 连续 7 天）。

### 6. 学习报告

- 本周 vs 上周：训练次数、活跃天数、正确率、XP、星数的对比与增减标注。
- Swift Charts：14 天训练量柱状图（上周淡色/本周实色）+ 正确率趋势面积图。
- 按类别与按方法的正确率拆分，自动生成「这周先做这件事」的一句话建议。

### 7. 同级别排名

- 离线模拟：按学员等级段与本周 XP 区间，用可复现的种子随机生成 8 名虚拟同伴（不联网、不上传数据，页面明确标注）。
- 展示排名、百分位、金银铜牌与「我」的高亮行；等级或 XP 变化后榜单随之重排。

### 8. 新增持久化字段

`xp`、`xpByDay`（逐日经验）、`goals`（目标列表）、`methodStats`（方法维度正确率，用于薄弱诊断与报告），全部向后兼容旧存档。

## 九、启动参数（调试/演示）

`-tab today|drill|library|profile`、`-screen flash|number|palace|wrong|curve|calendar|review|quest|goals|report|rank`、`-method <id>`、`-practice`（直达该法练习）、`-autostart`（跳过选阶直接答题）、`-seedDemo`（注入演示数据：9 天记录、复习卡、错题、XP 与目标，仅首次）


## 十、v4：分学龄段的闯关题库与玩法

### 1. 为什么按学龄段拆

同一套「概念配对 + 步骤定位」放到小学一二年级就是超纲。这里按认知水平切成四段，
每段换一种玩法，题干与选项都压到 12 字以内，避免长句阅读负担。

| 学龄段 | 认知特点 | 玩法 | 题型 | 关卡 | 时限 |
| --- | --- | --- | --- | --- | --- |
| 小学低年级 1–2 | 以图像为主，识字量有限 | 翻翻配对 | 词 ↔ 图（emoji）配对 | 12 关 × 3 | 60/55/50 秒 |
| 小学高年级 3–6 | 能理解流程，喜欢闯关 | 排排队 | 把 3/4/5 个步骤按序点出 | 12 关 × 3 | 75/70/65 秒 |
| 初中 7–9 | 抽象概念上手，争胜心强 | 限时抢答 | 归类 / 首步 / 辨识 / 衔接 四选一 | 12 关 × 3 | 60/55/50 秒 |
| 高中 10–12 | 学科材料为主，追求迁移 | 编码工坊 | 选方法 + 选编码路径 + 自评默写 | 9 关 × 3 | 不限时 |

### 2. 题库结构（Resources/quest.json）

- `kid`：12 个主题包（动物/水果/文具/自然/交通/食物/身体/天气/家居/乐器/运动/校园），每包 5 组词图。
- `order`：12 个流程清晰的方法（定位、数字形象、图像、故事链、口诀、组块、分类、大纲、导图、主动回忆、卡片、间隔重复）。
- `rush`：12 个主题，按七大类 + 五个应用场景（背单词/背课文/记公式/考前冲刺/综合）分组，共 12 关。
- `lab`：9 个学科（语文/英语/历史/化学/生物/地理/数学/物理/综合），每科 4 份真实材料并标注应使用方法。

题目不是死记的文本：初中四选一由出题引擎从 40 法知识库现生成（干扰项取自其他方法），
高中路径选项由各方法第 2–3 步拼成，避免背答案。

### 3. 计分与星级

- 每档独立记最好正确率，≥ 80% 得一颗星，每关三档共三颗；全段 45 关 × 3 = 135 星。
- 不同玩法有各自的计分口径：配对按「1 - 翻错×15%」，排序按「1 - 点错×20%」，抢答按答对率，工坊按两空全对率。
- 结算页统一显示正确率环、星、是否刷新记录，并写回 XP 与当日统计。

### 4. 交互细节

- 翻牌：点两张比对，错对会 0.48 秒后自动翻回，配对成功降透明度并描边。
- 排序：候选步骤点对后上移到「已排」列表；点错抖动并计数，不打断节奏。
- 抢答：答完 0.42 秒自动跳下一题，连击 ≥ 2 时显示「连击 ×N」，时间条最后 10 秒变红。
- 工坊：材料卡带「提示」灯泡，两步选完进入自评（记住了/还不熟），自评不进分数只影响提示。

### 5. 调试参数

`-game <stage> <node> <level>` 直达某关（stage: primaryLow / primaryHigh / junior / senior），
`-stage <stage>` 指定闯关地图默认学龄段，`-autoFinish` 让配对玩法直接结算，用于验证结果页。

## 十一、v6：图解案例库（样板：图像记忆法）

一个方法在详情页讲清「是什么」，案例库负责讲清「长什么样」。先做图像记忆法一种，结构可复用。

### 1. 内容结构

- 12 份真实材料，分三档：入门（具体名词）4 / 进阶（抽象词转具象、多元素串联）4 / 高阶（系统流程、学科概念、长序列）4。
- 每份材料给 **3 种不同思路**，合计 36 条：不是三个难度，而是三条并行的技术路线（如「夸张变形 / 动作赋予 / 位置挂放」），让用户找到自己最顺手的一条。
- 每条思路固定四段：**为什么有效**（一句原理）→ **操作步骤**（2–4 步）→ **串起来是这样**（成品句子，可直接照读）→ **提取钩子**（回忆时先想什么）。
- 数据落在 `Resources/imagecases.json`（约 25 KB），模型 `ImageCase` / `MemoryPath` / `CaseTier`，由 `CaseBank` 加载并排序。

### 2. 图文怎么做

不用网络图片：一是版权与上架风险，二是离线包体积。这里用 **emoji 图卡**（系统自带、零依赖、深浅主题都清晰）+
每个元素一个编号位，组成「材料 → 图像」的对照网格。字段 `CaseItem{text, emoji}` 预留了扩展位，后续要换成手绘插画，
只需替换渲染层，内容不用动。

### 3. 交互

- 列表：难度分段（入门/进阶/高阶，各 4 例）+ 卡片预览（前 5 个图像、材料摘要、三条思路名）。
- 详情：材料卡 → 图像网格 → 三思路分段器 → 思路卡 → 上/下一例（按难度顺序，不跨档跳）。
- **遮图自测**：一键把所有图卡变成「?」，点一张翻一张，用来检验「图像是否真的立住了」。这是这套页面里唯一需要动手的环节。
- 入口两处：方法详情（图像记忆法）内的「图解案例」卡；训练场 → 进阶玩法 →「图解案例」。

### 4. 调试参数

`-cases` 直接打开案例库，`-case <n>` 直达第 n 例（0 起，按难度序），配合 `-tab library -method 1` 使用。
